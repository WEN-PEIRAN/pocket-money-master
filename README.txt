POCKET MONEY MASTER — VERSION 1.6

- Delete Profile is integrated directly into js/app.js.
- Delete Profile appears in Profile Settings using the red liquid-glass button style.
- Existing Parent PIN is required when protection is enabled.
- A separate final irreversible-deletion warning is shown after PIN approval.
- Deletion removes the selected profile, all associated accounts and records, and leaves other profiles unchanged.
- The user returns directly to the profile-selection screen after deletion.
- V1.5 settings spacing, input symbols, card thumbnails, animations, transparent icons and localStorage compatibility are retained.
