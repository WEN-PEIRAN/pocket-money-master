POCKET MONEY MASTER — VERSION 2.7

Unified profiles
- Removed Adult/Child profile-type selection and labels.
- Every profile now uses the same full Accounts, Activity, Summary and Settings experience.
- New profiles are created directly with name, 4–6 digit Parent PIN, avatar, opening balance and card design.
- Existing Adult profiles migrate automatically: the adult savings account becomes a standard Savings Account, its balance/history/card/PIN are preserved, and a zero-balance Transaction Account is added when required.
- Existing profile cards show only avatar, profile name and combined balance.

Wallet UI
- Retains the fixed Wallet-style stacked cards and swipe navigation from V2.6.
- Add Account now uses a deep navy/blue near-opaque gradient with only slight translucency.
- The darker Add Account surface prevents the cards behind it from visibly showing through.

Retained
- Savings, Term Deposit and Investment engines.
- Share Market buy/sell, weekdays 3:00–6:00 pm Brisbane simulation, 10-minute updates and ±20% daily cap.
- Parent PIN protection, avatar selection, card artwork and navigation images.
- Root-level app files with images under img/.

V2.7 corrective update
- Fixed the top-right Add button so it opens Parent PIN approval and then Create Account.
- The top-right button now changes to Settings outside the Accounts tab and opens Settings.
- Restored the visible gold card chip on Wallet cards with fixed dimensions, block layout, gold gradient and subtle depth.
